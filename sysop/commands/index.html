    SYSOP command reference¶

    This list is generated from the current DXSpider help metadata. Commands marked DUAL contain both user and privileged variants.

    Command Guide Purpose
    ACCEPT/ANNOUNCE User + SYSOP Set an 'accept' filter line for announce
    ACCEPT/ROUTE SYSOP Set an 'accept' filter line for routing
    ACCEPT/SPOTS User + SYSOP Allow only DX spots that match one or more filter rules.
    ACCEPT/WCY User + SYSOP set an 'accept' WCY filter
    ACCEPT/WWV User + SYSOP set an 'accept' WWV filter
    ANNOUNCE User + SYSOP Send local, cluster-wide or SYSOP-only announcements.
    CATCHUP SYSOP Mark a message as sent
    CLEAR/ANNOUNCE User + SYSOP Clear a announce filter line
    CLEAR/DUPEFILE SYSOP Clear out the dupefile completely
    CLEAR/ROUTE User + SYSOP Clear a route filter line
    CLEAR/SPOTS User + SYSOP Remove one line or the complete DX spot filter.
    CLEAR/WCY User + SYSOP Clear a WCY filter line
    CLEAR/WWV User + SYSOP Clear a WWV filter line
    CONNECT SYSOP Start a connection to another DX Cluster
    CREATE/USER SYSOP Create this user from the User Database
    DBCREATE SYSOP Create a database entry
    DBEXPORT SYSOP Export an AK1A data to a file
    DBIMPORT SYSOP Import AK1A data into a database
    DBREMOVE SYSOP Delete a database
    DEBUG SYSOP Set the cluster program into debug mode
    DELETE/USDB SYSOP Delete this user from the US State Database
    DELETE/USER SYSOP Delete this user from the User Database
    DEMONSTRATE SYSOP Demonstrate a command to another user
    DIRECTORY User + SYSOP Browse DXSpider messages by ownership, age, sender, recipient, subject or message-number range.
    DISCONNECT SYSOP Disconnect user(s) or node(s)
    DOWNLOAD SYSOP Download a file into local_data
    DX User + SYSOP Send a DX spot into the cluster network.
    DXQSL_EXPORT SYSOP Export SH/DXSQL information to a file
    DXQSL_IMPORT SYSOP Import SH/DXSQL information from a file
    EXPORT SYSOP Export a message to a file
    EXPORT_USERS SYSOP Export the users database to ascii
    FORWARD/LATLONG SYSOP Send latitude and longitude information to another cluster
    FORWARD/OPERNAM SYSOP Send out information on this to all clusters
    GET/KEPS SYSOP Obtain the latest AMSAT Keplarian Elements from the web
    INIT SYSOP Re-initialise a link to an AK1A compatible node
    KILL User + SYSOP Delete a message from the local system
    LOAD/ALIASES SYSOP Reload the command alias table
    LOAD/BADIP SYSOP Reload the bad IP address table
    LOAD/BADMSG SYSOP Reload the bad msg table
    LOAD/BADWORDS SYSOP Reload the bad words table
    LOAD/BANDS SYSOP Reload the band limits table
    LOAD/CMD_CACHE SYSOP Reload the automatic command cache
    LOAD/FORWARD SYSOP Reload the msg forwarding routing table
    LOAD/KEPS SYSOP Load new keps data
    LOAD/MESSAGES SYSOP Reload the system messages file
    LOAD/PREFIXES SYSOP Reload the prefix table
    MERGE SYSOP Ask for the latest spots and WWV
    MSG SYSOP Alter various message parameters
    PC SYSOP Send text (eg PC Protocol) to
    PING User + SYSOP User level link check command
    RCMD SYSOP Send a command to another DX Cluster
    READ User + SYSOP Read the next unread personal message addressed to you
    REJECT/ANNOUNCE User + SYSOP Set a 'reject' filter line for announce
    REJECT/ROUTE SYSOP Set an 'reject' filter line for routing
    REJECT/SPOTS User + SYSOP Reject DX spots that match one or more filter rules.
    REJECT/WCY User + SYSOP set a 'reject' WCY filter
    REJECT/WWV User + SYSOP set a 'reject' WWV filter
    SAVE SYSOP Save command output to a file
    SEND_CONFIG SYSOP Broadcast PC92 C records
    SET/AGWENGINE SYSOP Enable the AGW Engine
    SET/AGWMONITOR SYSOP Enable Monitoring on the AGW Engine
    SET/ARCLUSTER SYSOP Make the callsign an AR-Cluster node
    SET/BADDX SYSOP Stop callsigns in a dx spot being propagated
    SET/BADIP SYSOP Stop logins and spots with this IP address
    SET/BADNODE SYSOP Stop spots from this node being propagated
    SET/BADSPOTTER SYSOP Stop spots from this callsign being propagated
    SET/BADWORD SYSOP Stop things like this word being propagated
    SET/BBS SYSOP Make the callsign a BBS
    SET/CCLUSTER SYSOP Make the callsign an CC Cluster node
    SET/CLX SYSOP Make the callsign an CLX node
    SET/DEBUG SYSOP Add a debug level to the debug set
    SET/DXNET SYSOP Make the callsign an DXNet node
    SET/HOPS SYSOP Set hop count
    SET/ISOLATE SYSOP Isolate a node from the rest of the network
    SET/LOCAL_NODE SYSOP Add node to the local_node group
    SET/LOCKOUT SYSOP Stop a callsign connecting to the cluster
    SET/MAXCONNECT SYSOP Set max incoming connections for user/node
    SET/NODE SYSOP Make the callsign an AK1A cluster
    SET/OBSCOUNT SYSOP Set the 'pump-up' obscelence PING counter
    SET/PASSWORD User + SYSOP Change your own password interactively, or—at SYSOP privilege—set another user's password.
    SET/PINGINTERVAL SYSOP Set ping time to neighbouring nodes
    SET/PRIVILEGE SYSOP Set privilege level on a call
    SET/RBN SYSOP Mark this call as an RBN node
    SET/REGISTER SYSOP Mark a user as registered
    SET/SKIMMER User + SYSOP [category ..]^Allow (some) RBN/Skimmer spotsT
    SET/SPIDER SYSOP Make the callsign an DXSpider node
    SET/STARTUP User + SYSOP Create a user startup script
    SET/SYS_LOCATION SYSOP Set your cluster latitude and longitude
    SET/SYS_QRA SYSOP Set your cluster QRA Grid locator
    SET/USDB SYSOP add/update a US DB callsign
    SET/USER SYSOP Make the callsign a normal user
    SET/WANTRBN User + SYSOP Choose which curated RBN/Skimmer categories are delivered to the user.
    SHOW/BADDX SYSOP Show all the bad dx calls in the system
    SHOW/BADNODE SYSOP Show all the bad nodes in the system
    SHOW/BADSPOTTER SYSOP Show all the bad spotters in the system
    SHOW/BADWORD SYSOP Show all the bad words in the system
    SHOW/CMD_CACHE SYSOP Show the real source path of commands
    SHOW/CONNECT SYSOP Show all the active connections
    SHOW/DEBUG SYSOP Show what levels of debug information you are logging
    SHOW/HOPS SYSOP Show the hop counts for a node
    SHOW/ISOLATE SYSOP Show list of ISOLATED nodes
    SHOW/LOCKOUT SYSOP Show the list of locked out or excluded callsigns
    SHOW/LOG SYSOP Show excerpts from the system log
    SHOW/NODE SYSOP Show the type and version number of nodes
    SHOW/PROGRAM SYSOP Show the locations of all the included program modules
    SHOW/RBN SYSOP Show which connected users want RBN spots
    SHOW/RCMD SYSOP Show log of rcmds
    SHOW/REGISTERED SYSOP Show the registered users
    SHOW/SPOTSTATS SYSOP Show the current Spot statistics
    SHOW/STARTUP User + SYSOP View a user startup script
    SHOW/STATION User + SYSOP Show list of users in the system
    SHUTDOWN SYSOP Shutdown the cluster
    SPOOF SYSOP Do a command as though you are another user
    STAT/CHANNEL SYSOP Show the status of a channel on the cluster
    STAT/DB SYSOP Show the status of a database
    STAT/MSG SYSOP Show the status of the message system
    STAT/ROUTE_NODE SYSOP Show the data in a Route::Node object
    STAT/ROUTE_USER SYSOP Show the data in a Route::User object
    STAT/USER SYSOP Show the full status of a user
    UNCATCHUP SYSOP Unmark a message as sent
    UNSET/AGWENGINE SYSOP Disable the AGW Engine
    UNSET/AGWMONITOR SYSOP Disable Monitoring on the AGW Engine
    UNSET/AK1A SYSOP Make the callsign a normal user
    UNSET/ARCLUSTER SYSOP Make the callsign a normal user
    UNSET/BADDX SYSOP Propagate a dx spot with this callsign again
    UNSET/BADNODE SYSOP Allow spots from this node again
    UNSET/BADSPOTTER SYSOP Allow spots from this callsign again
    UNSET/BADWORD SYSOP Propagate things like this word again
    UNSET/DEBUG SYSOP Remove a debug level from the debug set
    UNSET/HOPS SYSOP Unset hop count
    UNSET/ISOLATE SYSOP Stop Isolation of a node from the rest of the network
    UNSET/LOCAL_NODE SYSOP Remove node from the local_node group
    UNSET/LOCKOUT SYSOP Allow a callsign to connect to the cluster
    UNSET/NODE SYSOP Make the callsign a normal user
    UNSET/PASSWORD SYSOP Delete (remove) a user's password
    UNSET/REGISTER SYSOP Mark a user as not registered
    UNSET/SPIDER SYSOP Make the callsign a normal user
    UNSET/STARTUP User + SYSOP Remove a user startup script
    WX User + SYSOP Send a weather message to local users
