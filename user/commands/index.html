    User command reference¶

    This list is generated from the current DXSpider help metadata. Commands marked DUAL contain both user and privileged variants.

    Command Guide Purpose
    ACCEPT User Set a filter to accept something
    ACCEPT/ANNOUNCE User + SYSOP Set an 'accept' filter line for announce
    ACCEPT/RBN User Apply an accept filter specifically to RBN/Skimmer spots.
    ACCEPT/SPOTS User + SYSOP Allow only DX spots that match one or more filter rules.
    ACCEPT/WCY User + SYSOP set an 'accept' WCY filter
    ACCEPT/WWV User + SYSOP set an 'accept' WWV filter
    ANNOUNCE User + SYSOP Send local, cluster-wide or SYSOP-only announcements.
    APROPOS User Search help database for
    BLANK User Print nn (default 1) blank lines (or strings)
    BYE User Exit from the cluster
    CHAT User Chat or Conference to a group
    CLEAR/ANNOUNCE User + SYSOP Clear a announce filter line
    CLEAR/ROUTE User + SYSOP Clear a route filter line
    CLEAR/SPOTS User + SYSOP Remove one line or the complete DX spot filter.
    CLEAR/WCY User + SYSOP Clear a WCY filter line
    CLEAR/WWV User + SYSOP Clear a WWV filter line
    DBAVAIL User Show a list of all the Databases in the system
    DBSHOW User Display an entry, if it exists, in a database
    DIRECTORY User + SYSOP Browse DXSpider messages by ownership, age, sender, recipient, subject or message-number range.
    DISABLE/AUTOFTX User Suppress FT4/FT8 spots whose comments look automatically generated, while retaining more useful human-entered FT4/FT8 spots.
    DISABLE/FTX User Suppress all spots whose comment contains FT4 or FT8.
    DX User + SYSOP Send a DX spot into the cluster network.
    ECHO User Echo the line to the output
    ENABLE/AUTOFTX User Enable Autogenerated FT4/8 spots
    ENABLE/FTX User Enable ALL FT4/8 Spots
    FILTERING... User Filtering things in DXSpider
    HELP User The HELP Command
    JOIN User Join a chat or conference group
    KILL User + SYSOP Delete a message from the local system
    LEAVE User Leave a chat or conference group
    LINKS User Show which nodes is physically connected
    PING User + SYSOP User level link check command
    RBN User The Reverse Beacon or Skimmer System
    READ User + SYSOP Read the next unread personal message addressed to you
    REJECT User Set a filter to reject something
    REJECT/ANNOUNCE User + SYSOP Set a 'reject' filter line for announce
    REJECT/RBN User Set a 'reject' filter line for RBN spots
    REJECT/SPOTS User + SYSOP Reject DX spots that match one or more filter rules.
    REJECT/WCY User + SYSOP set a 'reject' WCY filter
    REJECT/WWV User + SYSOP set a 'reject' WWV filter
    REPLY User Reply (privately) to the last message that you have read
    SEND User Send a message to one or more callsigns
    SET/ADDRESS User Record your postal address
    SET/ANNOUNCE User Allow announce messages to come out on your terminal
    SET/ANNTALK User Allow talk like announce messages on your terminal
    SET/BEEP User Add a beep to DX and other messages on your terminal
    SET/BUDDY User Add this call to my buddy list
    SET/DX User Allow DX messages to come out on your terminal
    SET/DXCQ User Show CQ Zones on the end of DX announcements
    SET/DXGRID User Allow QRA Grid Squares on the end of DX announcements
    SET/DXITU User Show ITU Zones on the end of DX announcements
    SET/ECHO User Make the cluster echo your input
    SET/EMAIL User Set email address(es) and forward your personals
    SET/HERE User Tell DXSpider that you are present at your terminal.
    SET/HOMENODE User Set your normal cluster callsign
    SET/LANGUAGE User Set the language you want to use
    SET/LOCATION User Set your latitude and longitude
    SET/LOGININFO User Inform when a station logs in/out locally
    SET/NAME User Set your name
    SET/PAGE User Set the lines per page
    SET/PASSWORD User + SYSOP Change your own password interactively, or—at SYSOP privilege—set another user's password.
    SET/PROMPT User Set your prompt to
    SET/QRA User Set your QRA Grid locator
    SET/QTH User Set your QTH
    SET/SKIMMER User + SYSOP [category ..]^Allow (some) RBN/Skimmer spotsT
    SET/STARTUP User + SYSOP Create a user startup script
    SET/TALK User Allow TALK messages to come out on your terminal
    SET/USSTATE User Allow US State info on the end of DX announcements
    SET/WANTRBN User + SYSOP Choose which curated RBN/Skimmer categories are delivered to the user.
    SET/WCY User Allow WCY messages to come out on your terminal
    SET/WWV User Allow WWV messages to come out on your terminal
    SET/WX User Allow WX messages to come out on your terminal
    SHOW/ANNOUNCE User Show log of announces
    SHOW/BANDS User Show the list of bands and regions
    SHOW/BUDDY User Show your list of buddies
    SHOW/CHAT User Show any chat or conferencing
    SHOW/CONFIGURATION User Show all the nodes and users visible
    SHOW/CONFIGURATION/NODE User Show all the nodes connected locally
    SHOW/CONTEST User Show all the contests for a month
    SHOW/DATE User Show the local time
    SHOW/DB0SDX User Show QSL infomation from DB0SDX database
    SHOW/DX User Search the spot database by band, frequency, callsign, age, spotter, country, zone, state, origin, IP address and other selectors.
    SHOW/DXCC User Interrogate the spot database by country
    SHOW/DXQSL User Show any QSL info gathered from spots
    SHOW/DXSTATS User Show the DX Statistics
    SHOW/FDX User Show the DX data in realtime format.
    SHOW/FILES User List the contents of a filearea
    SHOW/FILTER User Show the contents of all the filters you have set
    SHOW/GRAYLINE User Show Civil dawn/dusk times
    SHOW/HFSTATS User Show the HF DX Statistics
    SHOW/HFTABLE User Show the HF DX Spotter Table
    SHOW/IK3QAR User Obtain QSL info from IK3QAR database
    SHOW/MOON User Show Moon rise and set times
    SHOW/MOTD User Show your MOTD (the Message of the Day)
    SHOW/MUF User Show the likely propagation to a prefix
    SHOW/MYDX User Search the spot database after applying your personal spot filter.
    SHOW/NEWCONFIGURATION User Show the cluster map
    SHOW/NEWCONFIGURATION/NODE User Show all the nodes connected locally
    SHOW/PREFIX User Interrogate the prefix database
    SHOW/QRA User Show distance between QRA Grid locators
    SHOW/QRZ User Show any callbook details on a callsign
    SHOW/ROUTE User Show the route to the callsign
    SHOW/SATELLITE User Show tracking data
    SHOW/STARTUP User + SYSOP View a user startup script
    SHOW/STATION User + SYSOP Show list of users in the system
    SHOW/SUN User Show sun rise and set times
    SHOW/TIME User Show the local time
    SHOW/USDB User Show information held on the FCC Call database
    SHOW/VHFSTATS User Show the VHF DX Statistics
    SHOW/VHFTABLE User Show the VHF DX Spotter Table
    SHOW/WCY User Show last 10 WCY broadcasts
    SHOW/WM7D User Show callbook details on a US callsigns
    SHOW/WWV User Show last 10 WWV broadcasts
    SYSOP User Regain your privileges if you login remotely
    TALK User Send a private talk message or enter interactive talk mode.
    TYPE User Look at the contents of a file in one of the fileareas
    UNSET/ANNOUNCE User Stop announce messages coming out on your terminal
    UNSET/ANNTALK User Stop talk like announce messages on your terminal
    UNSET/BEEP User Stop beeps for DX and other messages on your terminal
    UNSET/BUDDY User Remove this call from my buddy list
    UNSET/DX User Stop DX messages coming out on your terminal
    UNSET/DXCQ User Stop CQ Zones on the end of DX announcements
    UNSET/DXGRID User Stop QRA Grid Squares on the end of DX announcements
    UNSET/DXITU User Stop ITU Zones on the end of DX announcements
    UNSET/ECHO User Stop the cluster echoing your input
    UNSET/EMAIL User Stop personal msgs being forwarded by email
    UNSET/HERE User Tell DXSpider that you are absent from your terminal.
    UNSET/LOGININFO User No longer inform when a station logs in/out locally
    UNSET/PRIVILEGE User Remove any privilege for this session
    UNSET/PROMPT User Set your prompt back to default
    UNSET/SKIMMER User Stop all RBN/Skimmer spots
    UNSET/STARTUP User + SYSOP Remove a user startup script
    UNSET/TALK User Stop TALK messages coming out on your terminal
    UNSET/USSTATE User Stop US State info on the end of DX announcements
    UNSET/WANTRBN User Stop all RBN/Skimmer spots
    UNSET/WCY User Stop WCY messages coming out on your terminal
    UNSET/WWV User Stop WWV messages coming out on your terminal
    UNSET/WX User Stop WX messages coming out on your terminal
    WHO User Show who is physically connected
    WX User + SYSOP Send a weather message to local users
