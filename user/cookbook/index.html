    Command cookbook¶

    You do not need to know the command name first. Start with what you want to achieve.

    Show me the latest spots¶

    SHOW/DX

    Narrow the result:

    SHOW/DX ON 20M
SHOW/DX ON 20M INFO IOTA
SHOW/DX ZONE 14,15,16
SHOW/DX BY_ZONE 14,15,16
SHOW/DX IOTA EU-064
SHOW/DX QRA JN86

    The selectors can be combined. ZONE describes the spotted station; BY_ZONE describes the spotter.

    Find one exact callsign¶

    A simple callsign search can behave like a prefix search. Ask for an exact match when that matters:

    SHOW/DX HB2008G EXACT

    Search by origin or spotter IP¶

    SHOW/DX ORIGIN GB7TLH-4
SHOW/DX IP 82.65.128.4

    IPv6 is accepted too:

    SHOW/DX IP 2a00:1450:4009:800::200e

    I only want HF CW spots¶

    ACCEPT/SPOTS 1 ON HF/CW

    Inspect your filters:

    SHOW/FILTER

    Remove that rule:

    CLEAR/SPOTS 1

    Remove the complete spot filter:

    CLEAR/SPOTS ALL

    I want VHF spots involving Europe¶

    ACCEPT/SPOTS 1 ON VHF AND
  (BY_ZONE 14,15,16 OR CALL_ZONE 14,15,16)

    BY_ZONE tests the spotter. CALL_ZONE tests the spotted station.

    I want RBN CW but not every RBN mode¶

    SET/WANTRBN CW
ACCEPT/RBN 1 ON HF/CW

    RBN filtering has its own ACCEPT/RBN, REJECT/RBN and CLEAR/RBN family.

    I want FT4/FT8 but not machine-generated signal reports¶

    ENABLE/FTX
DISABLE/AUTOFTX

    This keeps useful FT4/FT8 spots while suppressing comments that DXSpider recognises as autogenerated, such as signal-report/frequency strings.

    To block all FT4/FT8 comments instead:

    DISABLE/FTX

    Search messages instead of scrolling through them¶

    DIRECTORY NEW
DIRECTORY OWN
DIRECTORY TO G1TLH 5
DIRECTORY SUBJECT IOTA 200-250
DIR/T G1* 10

    Talk to another operator¶

    One message:

    TALK G1ABC Hello John

    Interactive talk mode:

    TALK G1ABC

    While in talk mode, prefix normal DXSpider commands with /.

    Mark myself away without disconnecting¶

    UNSET/HERE

    When you return:

    SET/HERE

    These commands describe whether you are present at your terminal; they are not location commands.

    What nodes and users can I see?¶

    SHOW/CONFIGURATION

    For the complete known list:

    SHOW/CONFIGURATION ALL

    Be aware that the complete list can be very long.

    I don't know the command name¶

    Search the built-in help:

    APROPOS filter
APROPOS message
APROPOS rbn

    Then:

    HELP <command>
