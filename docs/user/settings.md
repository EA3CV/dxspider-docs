# Personal settings

Common user preferences include:

| Task | Command |
|---|---|
| Name | `SET/NAME` |
| Postal address | `SET/ADDRESS` |
| Email | `SET/EMAIL` / `UNSET/EMAIL` |
| Locator | `SET/QRA` |
| QTH | `SET/QTH` |
| Home node | `SET/HOMENODE` |
| Home BBS | `SET/HOMEBBS` |
| Language | `SET/LANGUAGE` |
| Terminal width | `SET/WIDTH` |
| Paging | `SET/PAGE` |
| Prompt | `SET/PROMPT` |
| Login information | `SET/LOGININFO` |
| Startup script | `SET/STARTUP` |
| RBN categories | `SET/WANTRBN` |

Most persistent preferences are stored in the user profile. Some commands also alter the current live session immediately.
