# Getting started

DXSpider commands are case-insensitive and can normally be abbreviated as long as the abbreviation is unambiguous.

```text
HELP <command>
APROPOS <string>
```

`HELP` opens the built-in command help. `APROPOS` searches that help by keyword.

Useful first commands:

```text
SHOW/DX
SHOW/CONFIGURATION
SHOW/STATION
WHO
SHOW/VERSION
```

To leave the node:

```text
BYE
```

!!! tip
    This web manual is organised by task, while the command reference is organised by command name. Use the site search when you already know part of a command.
