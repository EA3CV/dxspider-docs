## Documentation policy

The **current implementation is the source of truth**. Older manuals and wiki pages are used as supporting material only after their behaviour has been checked against the current code.

The site deliberately separates **normal user operations** from **SYSOP/administrative operations**. When one command has both forms, both are documented explicitly.
