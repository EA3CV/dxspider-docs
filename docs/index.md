## More than a command dictionary

The reference is generated from the current DXSpider help and command tree, but the site is organised around **questions and tasks**. A command page should tell you not only *what to type*, but *why you would use it*, *what its arguments mean*, and *how it fits with related commands*.

If the source does not support an explanation, the documentation does not invent one.
