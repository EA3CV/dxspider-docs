## Usage

```text
JOIN [token ...]
```

## Command description

```text
JOIN <group>
```

**Join a chat or conference group**

## Details

JOIN allows you to join a network wide conference group. To join a
group (called FOC in this case) type:-

```text
JOIN FOC
```

See also CHAT, LEAVE, SHOW/CHAT

## Verify on a running node
