## Usage

```text

```

## Command description

```text
LEAVE <group>
```

**Leave a chat or conference group**

## Details

LEAVE allows you to leave a network wide conference group. To leave a
group (called FOC in this case) type:-

```text
LEAVE FOC
```

See also CHAT, JOIN, SHOW/CHAT
