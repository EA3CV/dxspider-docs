## Purpose

Disconnect local users, nodes or groups of connections.

## Syntax

```text
DISCONNECT <callsign>|USERS|NODES|ALL
```


## Built-in help

On a running node, use:

```text
HELP DISCONNECT
```

The built-in help reflects the exact command set installed on that node.
