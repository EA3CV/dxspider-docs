## Syntax and variants

=== "SYSOP form"

    ```text
    STAT/ROUTE_USER <callsign>
    ```

    **Show the data in a Route::User object**


=== "SYSOP form"

    ```text
    STAT/ROUTE_USER all
    ```

    **Show list of all Route::User objects**
