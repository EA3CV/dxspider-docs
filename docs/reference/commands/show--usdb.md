## Usage

```text
SHOW/USDB [token ...]
```

## Command description

```text
SHOW/USDB [call ..]
```

**Show information held on the FCC Call database**

## Details

Show the City and State of a Callsign held on the FCC database if
his is being run on this system, eg:-

```text
sh/usdb k1xx
```

## Verify on a running node

```text
HELP SHOW/USDB
```
