## Purpose

Alias to LOAD/CMD_CACHE; clears/reloads the command cache.

## Syntax

```text
CLEAR/CMD_CACHE
```


## Built-in help

On a running node, use:

```text
HELP CLEAR/CMD_CACHE
```

The built-in help reflects the exact command set installed on that node.
