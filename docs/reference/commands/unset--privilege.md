## Purpose

Drops privilege for the current session.

## Syntax

```text
UNSET/PRIVILEGE
```


## Built-in help

On a running node, use:

```text
HELP UNSET/PRIVILEGE
```

The built-in help reflects the exact command set installed on that node.
