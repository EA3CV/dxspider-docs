## Syntax

```text
LOAD/FORWARD
```

**Reload the msg forwarding routing table**

## Details

Reload the /spider/msg/forward.pl file if you have changed it
manually whilst the cluster is running.

## Implementation

[View the current command source on GitHub](https://github.com/EA3CV/dxspider/blob/4904e1866076e1a4d0292caef36e994472a393b6/cmd/load/forward.pl){ .md-button }
