## Syntax and variants

=== "User form"

    ```text
    SHOW/WCY
    ```

    **Show last 10 WCY broadcasts**


=== "User form"

    ```text
    SHOW/WCY <n>
    ```

    **Show last <n> WCY broadcasts**

    Display the most recent WCY information that has been received by the system
