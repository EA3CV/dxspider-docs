## Purpose

Disable or clear `local_node`.

## Syntax

```text
UNSET/LOCAL_NODE
```


## Built-in help

On a running node, use:

```text
HELP UNSET/LOCAL_NODE
```

The built-in help reflects the exact command set installed on that node.
