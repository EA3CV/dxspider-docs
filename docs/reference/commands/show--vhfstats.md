## Usage

```text
SHOW/VHFSTATS [token ...]
```

### Available options and values

`cm`, `Date`, `m`, `mm`, `Total`

The valid combinations are described in the command forms and examples below.

## Command description

```text
SHOW/VHFSTATS [days] [date]
```

**Show the VHF DX Statistics**

## Details

Show the VHF DX spots breakdown by band for the last
<days> no of days (default is 31), starting from a date (default: today).

## Verify on a running node

```text
HELP SHOW/VHFSTATS
```

Use the node help to check for local overrides or differences in another installed revision.
