## Purpose

Shows node data-transfer statistics.

## Syntax

```text
SHOW/DATA_STATS
```


## Built-in help

On a running node, use:

```text
HELP SHOW/DATA_STATS
```

The built-in help reflects the exact command set installed on that node.
