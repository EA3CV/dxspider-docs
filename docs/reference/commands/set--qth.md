## Usage

```text
SET/QTH [text]
```

## Command description

```text
SET/QTH <your qth>
```

**Set your QTH**

## Details

Tell the system where you are. For example:-
```text
SET/QTH East Dereham, Norfolk
```

## Verify on a running node

```text
HELP SET/QTH
```

Use the node help to check for local overrides or differences in another installed revision.
